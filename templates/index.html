📘 How to Use the Last Resort Hotel Management Dashboard

Welcome to the Last Resort Hotel data dashboard. This system is designed to help management understand business performance and make data-driven decisions. Below is a quick guide to help you use the dashboard effectively.

🔎 Dashboard Overview

The navigation panel on the left provides access to eight predefined analytical queries. Each query page displays summarized results in a structured table format.

📋 What Each Section Does

  1. 📈 Monthly Revenue: View the total revenue generated per month from all services.
  2. 💰 Top Guests: Identify high-value guests based on total spending.
  3. 📊 Room Occupancy: Measure how often different room types are reserved.
  4. 💳 Deposit Overview: Analyze the average deposit amounts required by room type.
  5. 🛎️ Service Revenue: Examine which service types bring in the most income.
  6. 🍽️ Dining Stats: Review dining usage frequency and related revenue.
  7. 📆 Quarterly Breakdown: Analyze revenue across quarters by service type.
  8. 🛏️ Stay Duration: Explore how long guests typically stay in each room type.

📈 How to Use

  • Use the left-hand navigation to select any section above.
  • Each page shows a summarized table of live data from the database.
  • Use results to understand trends and improve management decisions.

🛠️ Notes

  • This dashboard is read-only. No data is altered or inserted from the interface.
  • If a page appears blank, verify that the underlying table has relevant data.

For technical support, contact your system administrator.
